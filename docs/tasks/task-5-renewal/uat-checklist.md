# UAT — ใบเตือนต่ออายุ InsureHub (งาน 5.5)

ClickUp: `z8qu5d0qw4` · ผู้ทดสอบ: ฝ่ายปฏิบัติการ · ระบบ: InsureHub (ต่ออายุ → รายละเอียดกรมธรรม์ → "จัดทำใบเตือนต่ออายุ InsureHub")

## ก่อนเริ่ม

- [ ] ตั้งค่าหน่วยงาน → ข้อมูลหน่วยงาน: ชื่อบริษัท, ที่อยู่, โทร, อีเมล, เว็บไซต์, เลขผู้เสียภาษี, ใบอนุญาตนายหน้า คปภ. **เป็นค่าจริง** (ใน dev ตอนนี้เป็นค่าทดสอบ)
- [ ] ช่อง "ช่องทางชำระเงิน (แสดงบนใบเตือนต่ออายุ)" เป็นบัญชี/พร้อมเพย์จริงของบริษัท
- [ ] โลโก้บริษัทแสดงถูกต้อง
- [ ] เตรียมใบเตือนจากบริษัทประกันของจริง 1 ใบต่อเคส (เพื่อเทียบตัวเลข)

## ขั้นตอนต่อเคส

1. เปิดกรมธรรม์ในคิวต่ออายุ → "อัปโหลดใบเสนอราคาบริษัท" แนบใบเตือนจากบริษัท
2. ที่ "จัดทำใบเตือนต่ออายุ InsureHub" กรอกเบี้ยรวม, ส่วนลด, ทุนประกันตามใบเตือนของบริษัท
3. เลือกสูตรแยกภาษีให้ตรงกับประเภท (ดูตารางด้านล่าง) หรือปิด "แยกอัตโนมัติ" แล้วกรอก net/อากร/VAT ตามใบของบริษัท
4. ตรวจวันครบกำหนดชำระ (ค่าเริ่มต้น = วันหมดอายุ) และ "ราคานี้ใช้ได้ถึง"
5. กด "สร้างใบเตือน PDF + บันทึก" → เปิด PDF จากรายการเอกสาร
6. ดูการ์ด "เทียบกับใบเตือนต่ออายุ" ในหน้าเดียวกัน

| ประเภท | สูตรที่ควรใช้ |
|---|---|
| Motor (ภาคสมัครใจ) / Non-motor ทั่วไป | สูตร 1 — อากร + VAT |
| Life | ปิด "แยกอัตโนมัติ" → net = เบี้ยรวม, อากร 0, VAT 0 (หรือตามใบของบริษัท) |
| สินค้าที่บริษัทคิดอากรคงที่ | สูตร 3 (อากร 20) / สูตร 4 (อากร 150) |
