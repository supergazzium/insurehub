## 2. ยอดที่ใช้วัด

- **ยอด** = ยอดชำระเบี้ย (`policy_payments.amount`) ของกรมธรรม์ที่ตัวแทนเป็นผู้ขาย นับตาม **วันที่ชำระ**
- **ยอดทีม** = ยอดของตัวเอง + ยอดของลูกทีม **ทุกชั้น** ที่ระดับ **ต่ำกว่า** ตัวเอง
  - ลูกทีมที่ระดับเท่ากันหรือสูงกว่า **ไม่นับ** แต่ลูกทีมของเขาที่ระดับต่ำกว่าเรายังนับ
  - ใช้ระดับ ณ ปัจจุบันของทุกคน
- **ยอดสะสม 3 เดือน** = ยอดทีมเดือนนี้ + 2 เดือนก่อนหน้า (เดือนปฏิทิน)
- การชำระที่ถูกลบหรือแก้ไข (ยอด/วันที่) → ยอดคำนวณใหม่ทันที · ชำระย้อนหลัง → ยอดสะสมของเดือนถัดไปถูกปรับด้วย
- ทุกคืน 02:00 ระบบคำนวณยอด 3 เดือนล่าสุดใหม่ทั้งหมด (กันตกหล่น)

## 3. ใบอนุญาต (Lv7 ขึ้นไป)

- นับว่า "มีใบอนุญาต" เมื่อมี **ใบอนุญาตชีวิต หรือ วินาศภัย** อย่างน้อย 1 ใบที่มีเลขที่และวันหมดอายุ **ยังไม่ถึง**
- ไม่มีวันหมดอายุ = ถือว่าไม่มี · ไม่มีใบอนุญาต → ระบบเสนอได้สูงสุด Lv6
- ตรวจซ้ำตอนกดอนุมัติ (ถ้าใบหมดอายุระหว่างรออนุมัติ จะอนุมัติไม่ได้)

## 4. การเลื่อน/ปรับระดับ

| ทาง | ขั้นตอน |
|---|---|
| ระบบเสนอ | ยอดสะสม 3 เดือนถึงเป้า → สร้างคำขอ "รออนุมัติ" (ข้ามระดับได้ เช่น Lv1 → Lv3) · มีคำขอระบบเสนอค้างได้ 1 รายการต่อคน (ถ้ายอดถึงระดับที่สูงกว่า รายการเดิมเป็น "ถูกแทนที่") |
| ขอปรับเอง | เจ้าหน้าที่ที่มีสิทธิ์ "แก้ไขตัวแทน" กด "ขอปรับระดับ" ในหน้าตัวแทน เลือกระดับ (ขึ้นหรือลงก็ได้) + เหตุผล (จำเป็น) · มีคำขอค้างได้ 1 รายการต่อคน |
| อนุมัติ | ผู้มีสิทธิ์ **"อนุมัติเลื่อนระดับ"** (`agents.rank_approve`) กดอนุมัติที่ ตัวแทน → รออนุมัติ → ระดับเปลี่ยนทันที · คำขออื่นที่ค้างอยู่และไม่สูงกว่าระดับใหม่ → "ถูกแทนที่" |
| ไม่อนุมัติ | ต้องระบุเหตุผล · ระดับไม่เปลี่ยน · ระบบจะไม่เสนอระดับเดิมซ้ำในเดือนเดียวกัน (เดือนถัดไปถ้ายังถึงเป้าจะเสนอใหม่) |

- เปลี่ยนระดับโดยตรงจากฟอร์มตัวแทน **ไม่ได้แล้ว**
- **ไม่มีการลดระดับอัตโนมัติ** ลดได้เฉพาะคำขอปรับเองที่ผ่านการอนุมัติ
- ทุกคำขอ/อนุมัติ/ไม่อนุมัติ/เปลี่ยนระดับ บันทึกใน audit log (ผู้ทำ เวลา เหตุผล ระดับเดิม→ใหม่)

## 6. ประเด็นที่ควรให้ธุรกิจยืนยัน

1. **Lv2 เป้า 0** — ระบบตีความว่า "มียอดขายใน 3 เดือน" ทำให้ตัวแทนที่มียอดขายครั้งแรกจะมีคำขอขึ้น Lv2 เข้ามาให้อนุมัติ ถ้าไม่ต้องการ ให้กำหนดเป้า Lv2 ในหน้าเกณฑ์
2. **ใบอนุญาต Lv7+** — Excel ต้นฉบับ (Sheet2) เขียนว่า Lv7+ สำหรับ "นายหน้าวินาศภัยที่มีใบอนุญาต" แต่ที่ตกลงคือ ใบชีวิต **หรือ** วินาศ — ถ้าต้องเป็นวินาศเท่านั้นแก้ได้ที่จุดเดียว (`App\Support\AgentLicense`)
3. **ตอนเริ่มทุกคน Lv1** — ตามกฎ "นับเฉพาะลูกทีมระดับต่ำกว่า" ลูกทีม Lv1 ของหัวหน้าที่ยังเป็น Lv1 จะยังไม่นับเป็นยอดทีม จนกว่าหัวหน้าจะได้ปรับระดับ ควรทยอยส่งคำขอปรับระดับหัวหน้าทีมตามข้อมูลจริง
4. ยอดใช้ "ยอดชำระเบี้ยรวม" (ไม่ใช่เบี้ยสุทธิ) และยังนับการชำระของกรมธรรม์ที่ยกเลิกภายหลัง (เงินคืนยังไม่ถูกหัก)
