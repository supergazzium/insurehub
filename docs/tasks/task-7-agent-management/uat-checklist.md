## E. ข้อมูลเดิมที่ควรตรวจระหว่าง UAT

- [ ] ตัวแทน ~17 รายที่ชื่อเป็นบริษัท/เลขภาษีขึ้นต้น 0 แต่ถูกเก็บเป็นบุคคลธรรมดา (เช่น IN210009, IN210013, IN220282, IN230393, IN240435, IN240497) → เปลี่ยนเป็นนิติบุคคล + กรอกชื่อนิติบุคคล/เลขภาษีให้ถูก
- [ ] ตัวแทน 19 รายที่ระบบเดิมตั้ง VAT ไว้ (ตอนนี้แสดง "มี VAT") → ยืนยันว่ารวม/ไม่รวม VAT ถูกต้อง
- [ ] ตัวแทน 3 รายที่เลขภาษี 12 หลัก → แก้ให้ครบ 13 หลัก
